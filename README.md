# MTA Food House — Digital Menu Board (Электронное ТВ-меню + Админ-панель)

Профессиональное веб-приложение **Digital Menu Board** (электронное меню для экранов и телевизоров в зале кафе) в соотношении сторон **16:9** для работы в полноэкранном режиме (1080p Full HD / 4K UHD) с **русскоязычной админ-панелью** для редактирования цен, блюд и загрузки фото прямо из браузера (с ноутбука или смартфона) с прямой синхронизацией в GitHub репозиторий.

> **Языковое разделение:**
> - 📺 **Витрина (экран телевизора для гостей в зале):** строго на **немецком языке** (часы, категории, аллергены, порции, цены, слоганы, подсказки киоска).
> - ⚙️ **Админ-панель (для владельца / администратора):** строго на **русском языке** (кнопки, формы, уведомления, статусы коммитов и ошибки).

## 🎨 Фирменный стиль (MTA Food House)

- **Основной фон**: теплый кремовый/светло-бежевый (`#F9F6E8`) с деликатной фоновой текстурой.
- **Основной акцент**: глубокий темно-зеленый (`#005826`) — заголовки, плашки, логотип, рамки.
- **Акцент для цен и плашек**: яркий солнечно-желтый (`#F4C414`) — цена в €, плашки бестселлеров, прогресс-бар слайдера.
- **Шапка экрана**:
  - Фирменные диагональные полосы MTA (темно-зеленый, белый, желтый ribbon).
  - Круглый логотип `logo.png` слева с эффектом интерактивного клика.
  - Крупное название категории блюд по центру (с плавным переходом).
  - Электронные часы (live clock с секундами) и статус Wi-Fi справа.

## 🔐 Русскоязычная панель администратора (/admin)

Управляйте всем меню с телефона, планшета или ноутбука без правки кода и без стороннего бэкенда:

### Как открыть админку:
1. **По прямой ссылке**: `https://<ваш-логин>.github.io/<репозиторий>/#/admin` (или `?admin=1`).
2. **Секретная комбинация**:
   - **Тройной быстрый клик по круглому логотипу MTA** в шапке экрана.
   - **Иконка щита** в плавающем меню киоска (появляется при движении мыши в правом нижнем углу).
   - **Горячие клавиши**: `Ctrl + Shift + A` или `Alt + A`.

### Защита и безопасность:
- При первом входе запрашивается **PIN-код** (по умолчанию `1234`, настраивается в панели) и **GitHub Personal Access Token (PAT)**.
- Токен и настройки безопасно сохраняются исключительно в `localStorage` вашего браузера и никогда не передаются третьим сервисам.

### Возможности админки:
- **Управление наличием блюд**: переключатель в один клик *"В наличии / Скрыто"* (выручает, когда блюдо закончилось на кухне — оно моментально исчезает из ТВ-слайдера).
- **Быстрое изменение цен**: кнопки `+0.50 €` / `-0.50 €` прямо в карточке блюда или точный ввод в редакторе.
- **Добавление новых блюд**:
  - Загрузка фото блюда на белой тарелке с **автоматическим сжатием в браузере (HTML5 Canvas до 800px)** перед отправкой в репозиторий.
  - Номер, название, категория, описание состава, аллергены, порция, плашки (*Bestseller*, *Hausrezept*, *Chef-Tipp*), отметки (*Vegetarisch*, *Scharf*).
- **Кнопка «Сохранить и опубликовать»**:
  - Загружает новые сжатые фото в папку `public/dishes/` через GitHub REST API.
  - Сохраняет весь массив данных в `public/data/menuData.json`.
  - Создает коммит в GitHub, запуская пересборку GitHub Pages.

## 📺 Авто-обновление ТВ без перезагрузки

Основной слайдер меню настроен на чтение данных из `public/data/menuData.json` с защитой от кэширования (`?_t=timestamp`).
В фоне работает автоматический опрос (раз в 60 секунд) — телевизор сам подтягивает обновленные блюда и цены без необходимости перезагружать страницу или подходить к телевизору!

## 📁 Структура проекта

```text
├── public/
│   ├── logo.png                       # Фирменный круглый логотип MTA Food House
│   ├── data/
│   │   └── menuData.json              # ЖИВОЙ JSON МЕНЮ (обновляется через админку и GitHub API)
│   └── dishes/                        # PNG-фотографии блюд без фона на белых тарелках
├── src/
│   ├── data/
│   │   └── menuData.ts                # Исходные типы TypeScript и локальный fallback
│   ├── services/
│   │   └── githubApi.ts               # REST API интеграция с GitHub (коммиты, загрузка фото, сжатие)
│   ├── components/
│   │   ├── admin/
│   │   │   ├── AdminPanel.tsx         # Главная админ-панель на русском языке
│   │   │   ├── AdminAuthModal.tsx     # Авторизация (PIN-код и GitHub Token) на русском
│   │   │   └── DishEditorModal.tsx    # Форма добавления/редактирования блюд на русском
│   │   ├── Header.tsx                 # Шапка ТВ (на немецком языке)
│   │   ├── DishShowcase.tsx           # Слайдер блюда ТВ (на немецком языке)
│   │   ├── CategoryBar.tsx            # Нижняя полоса ТВ (на немецком языке)
│   │   ├── CategoryPreviewList.tsx    # Превью блюд ТВ (на немецком языке)
│   │   └── KioskControls.tsx          # Скрытые кнопки киоска (на немецком языке)
│   ├── App.tsx                        # Главный компонент таймера, слайдов, роутинга и Fullscreen
│   ├── index.css                      # Tailwind и фирменные градиенты полос MTA
│   └── main.tsx
├── vite.config.ts                     # Конфигурация сборки с base: './' для GitHub Pages
└── package.json
```

## 🚀 Запуск и сборка

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск локально
```bash
npm run dev
```
* Меню для телевизора (немецкий интерфейс): `http://localhost:5173/`
* Админ-панель (русский интерфейс): `http://localhost:5173/#/admin`

### 3. Сборка для GitHub Pages
```bash
npm run build
```
Готовые статические файлы находятся в папке `dist/`.

## ⌨️ Горячие клавиши

| Клавиша / Комбинация | Действие |
|---|---|
| **F** или клик по логотипу | Переход в полноэкранный режим / Выход |
| **3 быстрых клика по логотипу** | Открыть админ-панель (/admin) |
| **Ctrl + Shift + A** (или **Alt + A**) | Открыть админ-панель |
| **→** (Стрелка вправо) / **Пробел** | Следующее блюдо на ТВ |
| **←** (Стрелка влево) | Предыдущее блюдо на ТВ |
