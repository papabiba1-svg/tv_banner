# MTA Food House — Digital Menu Board (Электронное ТВ-меню + Админ-панель)

Профессиональное веб-приложение **Digital Menu Board** (электронное меню для экранов и телевизоров в зале кафе) в соотношении сторон **16:9** для работы в полноэкранном режиме (1080p Full HD / 4K UHD) с **русскоязычной админ-панелью** для редактирования цен, блюд и загрузки фото прямо из браузера (с ноутбука или смартфона) с прямой синхронизацией в GitHub репозиторий.

> **Языковое разделение:**
> - 📺 **Витрина (экран телевизора для гостей в зале):** строго на **немецком языке** (названия блюд, состав, аллергены, цены, пометки «Inkl. MwSt.» и «Frisch zubereitet», формат времени).
> - ⚙️ **Админ-панель (для сотрудников и владельца):** строго на **русском языке** (кнопки, формы, уведомления, статусы коммитов и ошибки).

---

## 🎨 Премиальный дизайн экрана ТВ (MTA Food House)

- **Шапка (Header):**
  - Фирменные диагональные полосы MTA (темно-зеленый, белый, желтый ribbon).
  - Круглый логотип `logo.png` и название ресторана «MTA FOOD HOUSE» слева.
  - Текущие электронные часы в немецком формате справа.
  - Без лишних категорий, переключателей и плашек — чисто и презентабельно.
- **Главные элементы карточки блюда (чистый просторный Hero-экран):**
  - **Тарелка с блюдом:** плавное появление со сдвигом и живым эффектом непрерывного покачивания и левитации (`floating/swaying animation`) с дышащей тенью.
  - **Каскадное появление информации (Staggered Animation):**
    1. Крупное выразительное название блюда на немецком языке.
    2. Объемная стеклянная плашка с составом и описанием (`backdrop-blur-2xl`, мягкие тени).
    3. Аккуратный блок аллергенов и примечаний.
    4. Сочная золотая 3D-плашка цены в € с отметкой «Inkl. MwSt.» и «Frisch zubereitet».
- **Нижняя панель:** полностью убрана, внизу расположен ультра-тонкий золотистый индикатор таймера смены блюд.

## 🔐 Русскоязычная панель администратора (/admin)

Управляйте всем меню с телефона, планшета или ноутбука без стороннего бэкенда:

### Как открыть админку:
1. **По прямой ссылке**: `https://papabiba1-svg.github.io/tv_banner/#/admin` (или `?admin=1`).
2. **Секретная комбинация**:
   - **Тройной быстрый клик по круглому логотипу MTA** в шапке экрана.
   - **Иконка щита** в плавающем меню киоска (появляется при движении мыши в правом нижнем углу).
   - **Горячие клавиши**: `Ctrl + Shift + A` или `Alt + A`.

### Защита и безопасность:
- Запрашивается **PIN-код** (по умолчанию `1234`, настраивается в панели) и **GitHub Personal Access Token (PAT)**.
- Токен сохраняется исключительно в `localStorage` вашего браузера.

### Возможности админки:
- **Управление наличием блюд**: переключатель в один клик *"В наличии / Скрыто"*.
- **Быстрое изменение цен**: кнопки `+0.50 €` / `-0.50 €` прямо в карточке блюда или точный ввод.
- **Добавление новых блюд**:
  - Загрузка фото блюда на белой тарелке с **автоматическим сжатием в браузере (HTML5 Canvas до 800px)**.
  - Название, категория, описание состава, аллергены, порция, плашки (*Bestseller*, *Hausrezept*).
- **Кнопка «Сохранить и опубликовать»**:
  - Загружает новые сжатые фото в папку `public/dishes/` через GitHub REST API.
  - Сохраняет весь массив данных в `public/data/menuData.json`.
  - Создает коммит в GitHub, запуская автодеплой GitHub Actions.

## 📺 Авто-обновление ТВ без перезагрузки

Основной слайдер меню читает данные из `public/data/menuData.json` с защитой от кэширования (`?_t=timestamp`).
В фоне работает автоматический опрос (раз в 60 секунд) — телевизор сам подтягивает обновленные блюда и цены без необходимости перезагружать страницу!

## 🚀 Запуск и сборка

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск локально
```bash
npm run dev
```
* Меню для телевизора (немецкий интерфейс): `http://localhost:5173/tv_banner/`
* Админ-панель (русский интерфейс): `http://localhost:5173/tv_banner/#/admin`

### 3. Сборка для GitHub Pages
```bash
npm run build
```

## ⌨️ Горячие клавиши

| Клавиша / Комбинация | Действие |
|---|---|
| **F** или клик по логотипу | Переход в полноэкранный режим / Выход |
| **3 быстрых клика по логотипу** | Открыть админ-панель (/admin) |
| **Ctrl + Shift + A** (или **Alt + A**) | Открыть админ-панель |
| **→** (Стрелка вправо) / **Пробел** | Следующее блюдо на ТВ |
| **←** (Стрелка влево) | Предыдущее блюдо на ТВ |
